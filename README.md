# FlexCPR

## FlexCPR: A Flexible CPR Training System with Real-time Full-body Reconstruction and Adaptive Haptic Feedback

FlexCPR is an immersive virtual reality system for cardiopulmonary resuscitation (CPR) training. It integrates monocular full-body pose reconstruction, hand tracking, adaptive haptic feedback, and microphone-based artificial respiration detection into a lightweight training framework.

The system supports a five-stage CPR training workflow, including theoretical learning, chest compression training, artificial respiration training, and comprehensive performance assessment.

## Main Components

- Real-time full-body pose reconstruction from a monocular camera
- Part-level pose tokenization for CPR-related posture estimation
- Hand tracking and IK-based wrist position correction
- TPU-based pneumatic haptic feedback for chest compression
- Microphone-based artificial respiration detection
- Real-time CPR performance assessment in a VR environment
